Editor isi website

Cara pakai: ubah isi lewat formulir di bawah, klik Unduh content.js, lalu ganti berkas content.js di GitHub dengan berkas hasil unduhan. Cloudflare akan memperbarui website otomatis. Foto diisi dengan jalur berkas, misalnya assets/gedung.jpg (unggah fotonya ke folder assets di GitHub). Perubahan di halaman ini belum tersimpan sampai berkas diunduh dan diunggah.
